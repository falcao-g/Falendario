<h1 align="center"> Falendario 📅 </h1>
<blockquote>
<p><i>
Falendario is a Discord bot that provides a calendar system for users to create, manage, and share events to themselves and their friends.

It allows users to create events, set reminders, and view upcoming events in a user-friendly interface, in both private messages and discord servers. The bot is designed to help users stay organized and keep track of important dates and events in their lives.
</i></p>

</blockquote>

## 🚀 Features

- 📅 Unique calendar for each server and private channel
- ⏰ Reminders for upcoming events
- 📆 Create, edit, and delete events
- 📜 View events in a user-friendly interface
- 🌎 All features available in portuguese, english and spanish
